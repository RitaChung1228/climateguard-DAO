# ClimateGuard DAO Frontend

這是一個 Vite + React 的前端 MVP prototype，用來展示：

- 主辦方建立戶外活動
- 攤商加入 Weather Protection Plan
- Smart Contract Pool / Pool Health 的前端模擬
- Mock Weather Oracle 觸發 payout
- DAO Governance 調整 rainfall threshold / reserve ratio

## 如何執行

```bash
npm install
npm run dev
```

接著打開終端機顯示的本機網址，例如：

```bash
http://localhost:5173
```

## 注意

目前這版是 frontend mock prototype，尚未串接真正 smart contract。
適合先用於期末提案 demo、UI flow 展示與組內討論。
